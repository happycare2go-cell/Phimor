# คู่มือตั้งค่า Rich Menu — พี่หมอ

**อัปเดต:** ตอนนี้มีโค้ดสร้างและเชื่อม Rich Menu อัตโนมัติแล้ว (`backend/services/richMenuService.js`)
ไม่ต้องทำตามขั้นตอน Manual ทั้งหมดด้านล่างอีกต่อไป — คู่มือนี้ยังมีประโยชน์เพื่อ**เข้าใจโครงสร้าง**
และเป็นทางเลือกสำรองหากต้องการปรับแก้ผ่าน UI โดยตรง

## วิธีที่แนะนำ — ใช้ Script อัตโนมัติ

```bash
cd backend
# ① ตั้งค่า LIFF_ID_CENTER_ADMIN และ LIFF_ID_FAMILY ใน .env ให้เรียบร้อยก่อน
# ② รันครั้งเดียวตอน Deploy ครั้งแรก
node scripts/setup-rich-menus.js
```

Script นี้จะ:
```
① สร้าง Rich Menu ทั้ง 2 ชุดผ่าน LINE API พร้อมภาพที่เตรียมไว้ให้แล้ว
   (backend/assets/richmenu/center-admin.png และ family.png)
② ตั้งฝั่งครอบครัวเป็นเมนูเริ่มต้นให้ทุกคนอัตโนมัติ
③ เก็บ richMenuId ไว้ในฐานข้อมูล กันสร้างซ้ำถ้ารันซ้ำ
```

จากนั้น**ทุกครั้งที่มีการสร้างศูนย์ใหม่หรือแต่งตั้งผู้จัดการ** (`centerService.createCenter()` /
`appointManager()`) ระบบจะ**เชื่อม Rich Menu ฝั่งศูนย์ให้อัตโนมัติทันที** ไม่ต้องทำอะไรเพิ่ม

```
⚠️ เชื่อมเมนูให้คนที่ยังไม่ได้เพิ่มเพื่อน LINE OA ไม่ได้ (ข้อจำกัดของ LINE เอง ไม่ใช่บั๊ก)
   ถ้าสร้างบัญชีเจ้าของศูนย์ก่อนที่เขาจะเพิ่มเพื่อน OA การเชื่อมจะล้มเหลวเงียบๆ (log error ไว้)
   ไม่กระทบการสร้างศูนย์ เพราะออกแบบเป็น Fire-and-forget — ให้เจ้าของศูนย์เพิ่มเพื่อนก่อนเสมอ
   แล้วค่อยแต่งตั้งเป็น owner/manager
```

---

## ⚠️ คำถามที่ควรถามก่อนใช้ฟีเจอร์นี้: จำเป็นแค่ไหนจริงๆ

```
เจ้าของ/ผู้จัดการศูนย์มีจำนวนน้อยมากในเฟส 1 (8-40 คน) และทีมงานลงมือ Setup ให้ทุกศูนย์เองอยู่แล้ว
การเชื่อม Rich Menu อัตโนมัติจึงเป็นแค่การ "ลดขั้นตอนหนึ่ง" จาก Onboarding ที่ทำอยู่แล้ว
ไม่ใช่ฟีเจอร์ที่ขาดไม่ได้ — ถ้าไม่อยากใช้ Script นี้เลย ก็สามารถทำตามขั้นตอน Manual ด้านล่างแทนได้
```

---

## โครงสร้าง Rich Menu ทั้ง 2 ชุด (สำหรับเข้าใจ ไม่ต้องทำตามถ้าใช้ Script)

ระบบต้องมี Rich Menu แยก **2 ชุด** เพราะผู้ใช้ 2 กลุ่มมีสิทธิ์และหน้าจอคนละชุดกัน
ตั้งค่าผ่าน **LINE Official Account Manager** (https://manager.line.biz) ไม่ใช่ผ่านโค้ด

```
⚠️ พนักงานทั่วไปของศูนย์ "ไม่ต้องมี" Rich Menu ส่วนตัว
   เขาแค่อยู่ในกลุ่มไลน์งานศูนย์ ถ่ายรูปส่งเข้ากลุ่มธรรมดา ไม่ผ่านเมนูใดๆ ทั้งสิ้น
   ตามหลักการที่ตกลงกันไว้ตั้งแต่ต้น: "พนักงานรู้แค่ประโยคเดียว ถ่ายรูปแล้วส่งเข้ากลุ่ม"

   Rich Menu จึงมีไว้สำหรับ ① เจ้าของ/ผู้จัดการศูนย์ (แชทส่วนตัวกับบอท)
                            ② ครอบครัว (แชทส่วนตัวกับบอท)
```

---

## ชุดที่ 1 — Rich Menu ฝั่งศูนย์ (เจ้าของ/ผู้จัดการ)

### ข้อมูลทางเทคนิค

| หัวข้อ | ค่า |
|---|---|
| ขนาดภาพ | 2500 × 1686 px |
| รูปแบบไฟล์ | PNG หรือ JPEG ไม่เกิน 1 MB |
| จำนวนปุ่ม | 3 ปุ่ม แบ่งแถวเดียว |
| แสดงเมื่อไร | เฉพาะแชทส่วนตัวระหว่างเจ้าของ/ผู้จัดการกับบอท |

### ผังปุ่มที่แนะนำ (แบ่ง 3 ส่วนแนวนอน เท่าๆ กัน)

```
┌─────────────┬─────────────┬─────────────┐
│             │             │             │
│  จัดการ     │   รายการ    │  ติดต่อ     │
│  ผู้พัก      │  รอดำเนินการ │  ทีมงาน     │
│             │             │             │
└─────────────┴─────────────┴─────────────┘
```

| ปุ่ม | Action Type | ค่าที่ตั้ง |
|---|---|---|
| จัดการผู้พัก | `uri` | `https://liff.line.me/{LIFF_ID_CENTER_ADMIN}` |
| รายการรอดำเนินการ | `uri` | `https://liff.line.me/{LIFF_ID_CENTER_ADMIN}?view=transport` |
| ติดต่อทีมงาน | `message` | ข้อความ: `ติดต่อทีมงานพี่หมอ` |

**หมายเหตุ:** `?view=transport` ตอนนี้ทำงานแล้ว — `center-admin/index.html` อ่าน Query Parameter นี้
ตอนโหลดหน้าแล้วสลับไปแท็บ "รอดำเนินการ" อัตโนมัติ (ซึ่งตอนนี้รวมตารางนัดทั้งศูนย์ตามข้อ K1/K2 ด้วย)

## ชุดที่ 2 — Rich Menu ฝั่งครอบครัว

### ข้อมูลทางเทคนิค

| หัวข้อ | ค่า |
|---|---|
| ขนาดภาพ | 2500 × 1686 px |
| จำนวนปุ่ม | 4 ปุ่ม (2×2) |
| แสดงเมื่อไร | เฉพาะแชทส่วนตัวระหว่างครอบครัวกับบอท |

### ผังปุ่มที่แนะนำ

```
┌──────────────┬──────────────┐
│              │              │
│   หน้าหลัก    │  บันทึกนัด/ยา │
│              │              │
├──────────────┼──────────────┤
│              │              │
│  ดูประวัติ    │  ติดต่อ Admin │
│              │              │
└──────────────┴──────────────┘
```

| ปุ่ม | Action Type | ค่าที่ตั้ง |
|---|---|---|
| หน้าหลัก | `uri` | `https://liff.line.me/{LIFF_ID_FAMILY}` |
| บันทึกนัด/ยา | `uri` | `https://liff.line.me/{LIFF_ID_FAMILY}?view=record` |
| ดูประวัติ | `uri` | `https://liff.line.me/{LIFF_ID_FAMILY}?view=history` |
| ติดต่อ Admin | `message` | ข้อความ: `ติดต่อ Admin` |

**หมายเหตุ:** เช่นเดียวกับฝั่งศูนย์ — `?view=record` และ `?view=history` ทำงานแล้ว
`family/index.html` อ่าน Query Parameter นี้หลังโหลด Dashboard เสร็จ แล้วสลับแท็บให้อัตโนมัติ

## ขั้นตอนตั้งค่าจริงผ่าน LINE Official Account Manager

```
① เข้า https://manager.line.biz → เลือก OA "พี่หมอ"
② เมนู "Rich menu" → "Create a rich menu"
③ อัปโหลดภาพที่ออกแบบตามผังด้านบน (ใช้ Canva หรือ Figma ออกแบบตามขนาด 2500×1686)
④ กำหนด Tappable Area ให้ตรงกับตำแหน่งปุ่มในภาพ
⑤ ตั้งค่า Action ของแต่ละปุ่มตามตารางด้านบน
⑥ ตั้งชื่อ Rich Menu ให้แยกชัดเจน เช่น "phimor-center-admin-v1" และ "phimor-family-v1"
⑦ กด Publish
```

## ⚠️ วิธีแสดง Rich Menu คนละชุดให้คนละกลุ่มผู้ใช้

LINE ไม่มีการแสดง Rich Menu อัตโนมัติตามบทบาทผู้ใช้ ต้อง**ตั้งค่าเริ่มต้นเป็นชุดเดียว** (แนะนำฝั่งครอบครัว
เพราะมีผู้ใช้มากกว่า) แล้วให้ **Backend เรียก Link Rich Menu API สลับให้อัตโนมัติ** ตอนที่ระบบรู้ว่า
ผู้ใช้คนนี้เป็นเจ้าของ/ผู้จัดการศูนย์ (เช่น ตอน `centerService.createCenter()` หรือ `appointManager()` สำเร็จ)

```
POST https://api.line.me/v2/bot/user/{userId}/richmenu/{richMenuId}
Authorization: Bearer {LINE_CHANNEL_ACCESS_TOKEN}
```

**นี่คืองานที่ Dev ต้องเพิ่มใน `centerService.js`** — เรียก API นี้ในฟังก์ชัน `createCenter()` และ
`appointManager()` หลังบันทึกสำเร็จ เพื่อสลับ Rich Menu ของ Line User ID นั้นเป็นชุดฝั่งศูนย์อัตโนมัติ

```
☐ ทดสอบว่า LIFF ID ในปุ่มตรงกับที่ตั้งไว้ใน .env (LIFF_ID_CENTER_ADMIN, LIFF_ID_FAMILY)

```
