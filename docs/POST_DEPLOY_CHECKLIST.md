# รายการตรวจหลัง Deploy ระบบพี่หมอ

เอกสารนี้เรียงตามความเสี่ยง ควรตรวจจากข้อ 1 ลงไป และหยุด Deploy หากข้อระดับสูงไม่ผ่าน

## 1. สิทธิ์ผู้ใช้และแพ็กเกจ (สูงมาก)

- สร้างบัญชีทดสอบ Owner, Manager, Staff และ Staff ที่ถูกถอนสิทธิ์
- ให้ Staff ที่ถูกถอนสิทธิ์กดการ์ด LINE เดิม: ต้องเลือกผู้พัก เปิด แก้ไข หรือยืนยันการ์ดไม่ได้
- ให้ Manager ที่ยัง active เปิดและยืนยันการ์ด: ต้องทำได้
- ตั้งแพ็กเกจศูนย์ให้หมดอายุ แล้วทดสอบการ์ด LINE เดิม: ทุกการแก้ไขและยืนยันต้องถูกปฏิเสธ
- ระงับศูนย์จาก System Admin แล้วทดสอบซ้ำ: ต้องถูกปฏิเสธทันที

## 2. การตั้งแพ็กเกจจาก System Admin (สูง)

- เปิด System Admin LIFF บน LINE ทั้ง iPhone และ Android
- เลือกสาขา กำหนดวันเริ่ม วันหมดอายุ และประเภทแพ็กเกจ แล้วบันทึก
- รีเฟรชหน้า: วันที่และสถานะต้องคงอยู่ตรงกับค่าที่บันทึก
- ตรวจฐานข้อมูล Render ว่า `subscription_start_at`, `subscription_end_at` และ `subscription_package_type` เปลี่ยนจริง
- เจ้าของศูนย์ต้องได้รับ LINE แจ้งวันหมดอายุใหม่เพียงหนึ่งครั้ง

## 3. บทบาทบน Center LIFF (สูง)

- Staff ต้องเห็นรายชื่อผู้พักและ Clinical/Emergency Summary
- Staff ต้องไม่เห็นฟอร์มเพิ่มผู้พัก แท็บทีมงาน ราคาบริการ และรายการรอดำเนินการ
- Manager ต้องแก้ไขนัดและยกเลิกนัดได้ แต่จัดการบทบาททีมงานไม่ได้หากนโยบายกำหนดให้ Owner เท่านั้น
- Owner ต้องเข้าถึงทุกสาขาของตนผ่านตัวเลือกสาขาได้

## 4. นัดหมายและการแจ้งเตือน (สูง)

- แก้วันและเวลานัดผ่าน date/time picker แล้วตรวจว่าค่าที่แสดงเป็นเวลาไทยถูกต้อง
- แก้วันนัดแล้วสถานะการเตือนเดิมต้องถูกรีเซ็ต
- ยกเลิกนัดแล้วรายการต้องหายจากนัดที่จะถึง และไม่มีการเตือนอีก
- นัดจากครอบครัวและนัดที่ศูนย์ยืนยันต้องปรากฏกับ Care Profile คนเดียวกัน
- ทดสอบการเตือนก่อนวันนัดและวันนัด โดยตรวจว่าไม่ส่งซ้ำ

## 5. การลงทะเบียนและ PDPA (สูง)

- ผู้ใช้ใหม่เปิด Register LIFF กรอกข้อมูลไม่ครบหรือเบอร์ไม่ถูกต้อง: ต้องยังไม่สร้างศูนย์
- ลงทะเบียนสำเร็จ: บัญชี LINE ต้องเป็น Owner ของศูนย์ที่สร้าง
- Family LIFF ของผู้ใช้ใหม่ต้องแสดง PDPA ก่อนสร้างหรือผูก Care Profile
- ปฏิเสธ PDPA แล้วต้องยังไม่สามารถสร้างหรือผูก Care Profile

## 6. PDF และอุปกรณ์จริง (กลาง)

- สร้าง PDF ที่มีภาษาไทย ตรวจฟอนต์ Sarabun และระยะบรรทัด
- ทดสอบ Open, Download และ Share บน iPhone Safari/LINE LIFF
- ทดสอบบน Android LINE LIFF และ Chrome
- ตรวจว่าลิงก์หมดอายุหรือถูกแก้ไขแล้วเปิดไม่ได้

## 7. Flex Message, Rich Menu และมาสคอต (กลาง)

- ตรวจว่าปุ่มทุกปุ่มเปิด LIFF หรือส่ง postback ไปยังรายการที่ถูกต้อง
- ทดสอบการ์ดเก่าหลังถอนสิทธิ์และหลังแพ็กเกจหมดอายุ
- ตรวจรูปบนเครือข่ายมือถือช้า: หากรูปไม่โหลด ปุ่มและข้อความต้องยังใช้งานได้
- หากมาสคอตทับปุ่ม ทำให้เลื่อนยาก หรือทำให้ลำดับข้อมูลผิด ให้ซ่อนภาพทันทีโดยคงข้อความและปุ่มหลักไว้

## 8. สุขภาพระบบและงานตามเวลา (กลาง)

- เปิด `/health` และตรวจว่า `status` พร้อมใช้งาน, database เป็น true และไม่มี environment ที่ขาด
- ตรวจ scheduler heartbeat หลัง Deploy
- ตรวจ notification outbox ว่าไม่มีรายการ pending เก่านานผิดปกติหรือ dead letter เพิ่มขึ้น
- ตรวจ Render logs หลังทดสอบทุก flow ว่าไม่มี error 401/403/402/500 ที่ไม่คาดหมาย

## เกณฑ์ผ่านก่อนใช้งานจริง

- ข้อ 1-5 ต้องผ่านทั้งหมด
- ไม่มีข้อมูลข้ามศูนย์หรือข้าม Care Profile
- ผู้ถูกถอนสิทธิ์และศูนย์หมดอายุใช้งานข้อมูลไม่ได้ทันที
- การกดซ้ำไม่สร้างนัด ยา การ์ด หรือการแจ้งเตือนซ้ำ
- UI ต้องยังใช้งานได้แม้ภาพมาสคอตโหลดไม่สำเร็จ
