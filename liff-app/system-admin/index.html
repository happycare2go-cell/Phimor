ภาพรวมระบบ

ตรวจสาขา แพ็กเกจ และ Care Profile ได้จากศูนย์กลางครับ

รายการใกล้หมดอายุและสาขาที่ยังไม่ได้กำหนดแพ็กเกจควรได้รับการตรวจสอบก่อน

สาขาทั้งหมด

ตรวจสอบการชำระ Consult Case

ค้นหาแบบตรงตัวด้วยเลขอ้างอิง PHIMOR, Consult Case ID หรือ Omise Charge ID โดยไม่ใช้ยอดเงินหรือข้อมูลสุขภาพในการเดารายการ

คำขอเกี่ยวกับข้อมูลส่วนบุคคล

คิวดำเนินงานแบบควบคุม แสดงข้อมูลผู้ขอเท่าที่จำเป็น

การเปลี่ยนสถานะคำขอไม่ลบ ส่งออก แก้ไข หรือจำกัดข้อมูลอัตโนมัติ ผู้ปฏิบัติงานต้องดำเนินการตามขั้นตอนที่ได้รับอนุมัติและเก็บหลักฐานอย่างเหมาะสม

ศูนย์และระบบเชื่อมต่อ

ตั้งค่าความสามารถ เชื่อมผู้พัก และตรวจสอบเส้นทางแจ้งครอบครัว โดยไม่เปิดดูข้อมูลสุขภาพ

เข้าสู่ระบบเพื่อโหลดข้อมูลงานระบบ
